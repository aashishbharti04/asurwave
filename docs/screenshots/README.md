# Screenshots

Place README screenshots in this folder. The main `README.md` references:

| File             | Suggested capture                          |
| ---------------- | ------------------------------------------ |
| `hero-dark.png`  | Hero section in **dark** theme (1280×800)  |
| `hero-light.png` | Hero section in **light** theme (1280×800) |
| `mobile.png`     | Mobile view with the menu open (375×812)   |

## How to capture

```bash
npm run build && npm run preview
```

Open the preview URL, then use your browser's device toolbar (or a tool like
Playwright) to capture each viewport. Optimize PNGs before committing (e.g. with
[squoosh.app](https://squoosh.app)) to keep the repository lightweight.
